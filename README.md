# Susi Core (retired)

Susi Core was the public, Apache-2.0 library repository of the Susi
ecosystem. It was retired on 2026-11-23 by the decision of IntelliBitz's CEO.
Susi, the product, builds on none of its libraries since that day, and every
line of a public Susi repository must serve Susi or the agents who build it.

This repository takes no further changes. Its code stays available under the
Apache License, Version 2.0, in its history: the last commit holding it is
`ac88bca9aa9ca7cd3f12adb54845308296d7a070`.

The development tooling of the Susi ecosystem, public and Apache-2.0, is Susi
Tools: <https://github.com/intellibitz/susi-tools>.

(Section 6).
